很多朋友订阅了 Google AI Pro 或 Ultra 会员，平时只拿来在网页端用 Gemini 和 Antigravity，其实账上还躺着一笔很容易被忽略的福利：Google Cloud 赠金。

Google 每个月都会通过 Developer Program 给订阅用户发放 Google Cloud 赠金，并且还能叠加新用户的 300 美元免费试用金。以 Ultra 5x 为例，第一个月手里直接就有 340 美元额度可用。而且就算下个月退订了会员，已经发到账上的月度赠金也不会被收回，照样有整整 1 年有效期。

![](https://img.heyyao.com/2026/11/52ff31de2bf3617bd30a9622b077ab57.png)

这笔钱除了可以零成本从零开一台台湾原生服务器（再把 SSH 权限交给 Claude Code / Agent 自动运维），还可以搭配 google-genai SDK 的 vertexai=True，在自己写 Python / Go 跑批量任务时直接消耗 GCP 赠金、享受更高的生产级并发。

很多人不敢碰 Google Cloud，主要是怕绑卡后超支被反薅。先吃颗定心丸：只要你不主动点击升级成付费账号，试用期就算额度用完也只会停机，绝不会扣银行卡一分钱。

## 一、先算清楚能领多少钱，以及去哪领

你能拿到的额度一共分两笔，可以打进同一个 Google Cloud 结算账号里合并使用：

1. Google AI 订阅自带的月度赠金（通过 Google Developer Program 按月发放）：
![](https://img.heyyao.com/2026/11/1b8933fc9d8edbb4d987baf9e79537a1.jpeg)

1. Google Cloud 新用户免费试用金：一次性发放 300 美元（或等值外币，如约 ¥46,878 日元），有效期 90 天。
### 方式一：直接在 AI Studio 一键领取（最省事）

1. 用开通订阅的 Google 账号登录 Google AI Studio
1. 点开左侧导航栏弹出的未领取赠金提示，依次点击 Claim Google Cloud Credits 和 Redeem and Continue
1. 如果之前没建过 Developer Program 资料或 GCP 结算账号，系统会在这一步顺带建好
1. 领完后打开 AI Studio Billing 即可随时查看余额
### 方式二：通过 Developer Program 权益页领取

如果在 AI Studio 里没刷出入口，可以走官方权益页：

1. 打开 Developer Program Benefits
1. 选择接收赠金的 Google Cloud 结算账号，顺手勾选 Always use this billing account，以后每月赠金会自动入账
1. 如果页面给的是一串兑换码，复制后去 Cloud Billing Redeem 粘贴兑换
两笔都领完后，在 Cloud 控制台「结算 → 赠金（Credits）」页面可以看到每笔额度的起止时间（例如 300 美元试用金 90 天有效，40 美元 Ultra 赠金 12 个月有效）。

两个常见卡点提醒：

- 订阅赠金只有主订阅人本人能领，家庭组成员没有资格。
- 赠金一旦打进某个结算账号就无法转移，浏览器登录了多个 Google 账号时务必看准右上角头像再操作。

## 二、动手前必看的规则与红线（防反薅核心）

虽然两笔钱在同一个结算账号里，但它们的抵扣范围和过期机制完全不同：

| 对比项 | 300 美元新用户试用金 | 订阅月度赠金（$10 / $40 / $100） |
| --- | --- | --- |
| 有效期与节奏 | 一次性发放，90 天清零 | 按首次领取的月度周年日发放，每笔独立计算 12 个月有效期 |
| 抵扣 AI Studio Gemini API | 不支持 | 支持 |
| 抵扣 Vertex AI | 2026 年 11 月 16 日及以后注册/升级的试用金已不支持（老账号/早先领取的仍可） | 支持 |
| 开虚拟机服务器（GCE） | 支持 | 支持 |

必须记牢的避坑铁律：

- 绝对不要点「激活/升级到付费账号」：一旦升级，赠金扣完的下一秒就会直接从绑定的银行卡扣费。
- 退订会员不收回已发赠金：退订只是下个月不再发新钱，已经进账的额度照样满 1 年才过期。
- 扣款先后顺序不透明：同一结算账号有多笔赠金时，官方未公开扣款优先级。
- 赠金不报销的项目：Spot / 抢占式实例、承诺使用折扣（CUD）、Marketplace 镜像、第三方商业许可证，以及部分特殊机型和 GPU。
- 试用期硬限制：不能挂 GPU、不能用 Marketplace、不能申请提配额、不能开 Windows 服务器，且严禁挖矿。

## 三、不止开服务器：用 vertexai=True 跑高并发 Gemini 批量任务

很多写 Python / Go 脚本的朋友习惯直接去 AI Studio 拿个 api_key 调 Gemini，但经常遇到两个问题：

1. AI Studio 的小额体验金（例如 $10）跑批量任务很快就会烧完；

## 四、340 美元怎么花最划算：选台湾还是选香港？

在 Google Cloud 开服务器，每月的真实开销由四部分组成：机器配置 + 磁盘 + 公网 IPv4 + 出站流量。

### 1. 各区域机器月租参考

以下按需月租参考自 gcloud-compute.com（台湾 e2-medium 已在控制台核对一致）：

- 美国 us-central1：e2-small（2G）约 $12.2 / 月，e2-medium（4G）$24.46 / 月，e2-standard-2（8G）约 $48.9 / 月
- 台湾 asia-east1：e2-small（2G）约 $14.2 / 月，e2-medium（4G）$28.32 / 月，e2-standard-2（8G）约 $56.6 / 月
- 东京 asia-northeast1：e2-small（2G）约 $15.7 / 月，e2-medium（4G）$31.38 / 月，e2-standard-2（8G）约 $62.8 / 月
- 香港 asia-east2：e2-small（2G）约 $17.1 / 月，e2-medium（4G）$34.22 / 月，e2-standard-2（8G）约 $68.4 / 月
别忘了每月还有两笔固定底座费：

- 公网 IPv4 地址：$0.005 / 小时，约 $3.65 / 月
- 20 GB 平衡永久性磁盘：约 $2 / 月
### 2. 网络层级：决定流量费的核心开关

- 高级层级（系统默认）：走 Google 全球骨干网，回大陆线路质量稳，但没有免费流量。发往亚洲（含香港）$0.12 / GB，发往中国大陆 $0.23 / GB。
- 标准层级（需手动切换）：走普通运营商公网，不支持 IPv6，但每个区域每月白送 200 GB 免费流量（超出后美国区 $0.085 / GB 起）。如果在两个不同区域各开一台标准层级机器，每月就有 400 GB 免费额度。
### 3. 为什么推荐选台湾而不是香港？

- 更便宜：同配置下台湾比香港便宜约 20%。
- AI 生态支持好：台湾在 Gemini、ChatGPT、Claude 三大主流 AI 的官方支持地区内，而香港均不在支持范围内。想在服务器上跑 AI 工具或调接口，选台湾能省掉大量折腾。
### 4. 两套抄作业方案（按 340 美元跑 90 天估算）

- 方案 A：高级层级求稳，只开一台（最省心）
- 方案 B：标准层级求大流量，双区开两台

## 五、第一步：先设预算提醒（避开 90% 人踩的静默坑）

正式开机前先把账单警报拉上。打开 Google Cloud 控制台，进入左侧「结算」页面，点下方的「预算和上限」，再点右侧「新建」。

![](https://img.heyyao.com/2026/11/a73c794f89b616d168f80333d4e3b1f9.jpeg)

### 1. 定义：选「仅提醒」，别碰支出上限

保持勾选仅提醒（适用于所有服务），填一个预算名称后点下一步。

![](https://img.heyyao.com/2026/11/241777acf2223f32832a835c8fa26a7d.jpeg)

> 不要勾选「强制执行支出上限」——该功能只支持 Cloud Run、Cloud Run Functions、Gemini API 和 Vertex AI，且每个预算只能盯单个项目里的一项服务，管不到虚拟机和流量费。

### 2. 范围：取消勾选全部节省项（重中之重）

时间范围选「自定义范围」，开始日期保留默认的年初不动，勾选「无结束日期」，项目和服务保持全选。最底下「节省的费用」一栏，把「节省计划」和「其他节省」两个勾全部去掉。

![](https://img.heyyao.com/2026/11/4ac6feb58feda9a2b27a48b8670cd08c.jpeg)

为什么必须去掉？
试用金和订阅赠金在账单系统里都算作「其他节省」。一旦勾上，系统统计的是抵扣完赠金后的自付净额（永远为 0），哪怕 340 美元快烧光了也不会发邮件提醒。开始日期也不要手改到注册当天，避免因为美国太平洋时间时差漏算前几个小时的开销。

### 3. 金额与操作：填入总额并开启邮件警报

预算类型选「指定金额」，目标金额填入总额（例如 340）。

![](https://img.heyyao.com/2026/11/5e77fc5870d1a98c70fbda23538a0009.jpeg)

提醒阈值建议设为 50%、90%、100%（也可以再加一档 25%），触发对象选「实际支出」，勾选下方的向结算管理员和用户发送邮件提醒，点「完成」即可。

![](https://img.heyyao.com/2026/11/88044d68b0d5ed2389503e78b7fe0c35.jpeg)

## 六、第二步：全程点鼠标，开一台台湾服务器

回到控制台首页，确认左上角当前项目是 My First Project。点开左上角导航菜单，找到 Compute Engine → 虚拟机实例。

![](https://img.heyyao.com/2026/11/4a37f0332b876c783c55edf7a5cb6894.jpeg)

新账号第一次进入需要先启用 Compute Engine API，直接点击「启用」并等待 1~2 分钟初始化完成。

![](https://img.heyyao.com/2026/11/6513780ab4a233136c6a412533661b66.jpeg)

进入虚拟机实例列表后，点击「创建实例」。表单只需要改以下四处，其余保持默认：

![](https://img.heyyao.com/2026/11/f7526a05c4872e79b7be4cdf9fa4dcfa.jpeg)

### 1. 机器配置：锁定台湾与 E2 机型

名称保持默认或改成 tw-1。区域下拉选择 asia-east1（台湾），可用区保持不限或选 asia-east1-b。机器类型在「通用」下选 E2 系列，预设规格选 e2-medium（2 vCPU、4 GB 内存）。

![](https://img.heyyao.com/2026/11/8c02b7b5a2a149bcd7d6f14c1249c344.jpeg)

> 注意：右侧估算值（20 GB 磁盘约 $30.32）不包含公网 IPv4（约 $3.65 / 月）和出站流量费，算账时记得加上。

### 2. 操作系统和存储：Debian 13 + 20 GB 磁盘

点左侧「操作系统和存储空间」→「更改」，操作系统选 Debian，版本选 Debian GNU/Linux 13 (trixie)，启动磁盘保持「平衡的永久性磁盘」，大小改为 20 GB，点「选择」确认。

![](https://img.heyyao.com/2026/11/a40377994c13fa9aa24a7e05a8042fac.jpeg)

### 3. 数据保护：关掉备份省快照费

切到左侧「数据保护」，把备份改为无备份，避免后台自动打快照消耗额度。

![](https://img.heyyao.com/2026/11/f61b62be7605f3c35f3d74f5c0618ff5.jpeg)

### 4. 网络：确认临时 IP 与网络服务层级

切到左侧「网络」，需要建站就勾选 HTTP / HTTPS 防火墙，只跑工具可以不勾。展开 default 网络接口，确认外部 IPv4 为「临时」，底部的 Network Service Tier（网络服务层级） 按方案选择（求稳选「高级」，求每月 200 GB 免费流量选「标准」）。

![](https://img.heyyao.com/2026/11/d52f8a0cb626993b7eed071d4b4d6c3e.jpeg)

全部核对完毕点击「创建」，等待约半分钟，列表亮起绿勾并分配外部 IP 后就正式落地了。

## 八、日常避坑与 90 天到期退场指南

日常使用五个提醒：

1. 关机重启会换公网 IP：默认的临时 IP 在关机再开机后会变化；若提升为静态 IP，注意机器关停导致静态 IP 闲置时单价会翻倍涨到 $0.01 / 小时。
1. 停止不代表完全停费：停止虚拟机后算力不收钱，但 20 GB 磁盘仍按月计费，彻底不用请直接「删除」。
1. 端口放行：默认只开 22 端口，部署服务需去「VPC 网络 → 防火墙」按需放行端口。
1. 每周巡检流量费：在「结算 → 报告」中按 SKU 搜索 Network Internet Egress，即可查看真实出站流量开销。
1. 严禁卖号或代跑：触犯风控不仅云账号清零，还会连累主 Google 账号。
90 天试用到期会怎样？

- 不升级就绝对不扣卡：只要停留在试用账号状态，所有消耗全走赠金抵扣。
- 自动停机触发线：300 美元试用金用完，或者满 90 天，先到者触发自动关停，停机后留 30 天宽限期备份数据。
- 按 300 美元封顶规划最稳：收到 90% 预算提醒邮件当天就建议备份重要数据，因为 300 美元试用金耗尽后同账号里未花完的月度赠金也可能受停机影响。
- 想长期免单：如果后续每月仍有 Ultra 赠金，可在到期前将机器降配到月度赠金能覆盖的规格（如台湾 e2-small 配标准网络层级，约 $21 / 月），确认预算提醒正常后再升级为付费账号；或者升级后去美国 us-west1 / us-central1 / us-east1 开一台 e2-micro（含 30 GB 标准磁盘与每月 1 GB 出站流量），属于 Google Cloud 永久免费额度。
