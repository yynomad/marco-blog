## 前言

家里有了孩子之后，我开始思考一个问题：

> 有没有一种方式，可以把喜欢的动画片、纪录片和电影集中管理，随时在电视、手机或者平板上观看？

市面上的流媒体平台虽然方便，但也存在一些问题：

- 会员越来越多
- 内容会下架
- 不同平台内容分散
- 孩子喜欢的动画片不一定长期存在
于是我利用家里现有的设备，搭建了一套属于自己的家庭影音系统。

最终只用了：

- 一台旧电脑
- 一个移动硬盘
- Jellyfin
就实现了接近 Netflix 的体验。

# 最终效果

```plain text
WD移动硬盘
      ↓
Redmi Book Pro 2024
      ↓
Jellyfin
      ↓
家庭WiFi
      ↓
电视 / 手机 / 平板
```

可以实现：

- 动画片分类管理
- 电影海报墙展示
- 家庭共享
- 手机和平板观看
- 观看进度同步
- 收藏喜欢的影片
对于有孩子的家庭来说尤其方便。

# 为什么选择 Jellyfin

目前主流的家庭影音方案有：

对于技术人员来说，Jellyfin 几乎是首选。

优点：

- 完全免费
- 开源可控
- 社区活跃
- 支持 Docker
- 支持手机、平板、电视
- 无会员限制
最重要的是：

> 所有数据都掌握在自己手里。

# 硬件准备

我使用的是：

- Redmi Book Pro 2024
- WD 移动硬盘
- iPhone
- 家庭 WiFi
实际上要求并不高：

```plain text
CPU：4核以上
内存：8GB以上
存储：1TB以上
```

普通笔记本即可流畅运行。

# 目录规划

在移动硬盘中创建媒体目录：

```plain text
Media
├── Movies
├── TVShows
└── Anime
```

例如：

```plain text
Media
└── Movies
    ├── Finding Nemo (2003)
    │   └── Finding Nemo (2003).mkv
    ├── Frozen (2013)
    │   └── Frozen (2013).mkv
    └── Zootopia (2016)
        └── Zootopia (2016).mkv
```

建议：

> 每部电影单独一个文件夹。

# 安装 Jellyfin

前往：

Jellyfin 官网

下载安装包。

安装完成后可以访问这个地址试一下

```plain text
http://localhost:8096
```

首次启动需要：

1. 创建管理员账号
1. 设置语言
1. 创建媒体库
按照向导完成即可。

# 创建媒体库

进入后台：

```plain text
Dashboard
→ Libraries
→ Add Library
```

选择：

```plain text
Movies
```

然后指定路径：

```plain text
E:\Media\Movies
```

点击保存。

# 手机访问

确保手机和电脑连接到同一个 WiFi。

首先查看电脑 IP 地址。

Windows：

```plain text
ipconfig
```

找到：

```plain text
IPv4 Address
```

例如：

```plain text
192.168.1.100
```

然后在手机浏览器中访问：

```plain text
http://192.168.1.100:8096
```

即可进入 Jellyfin。

也可以安装官方客户端获得更好的体验。
